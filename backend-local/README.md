# Servicio local de avatar y RAG

Servicio Python usado para desarrollo local del avatar, voz y recuperación de documentos. Sus modelos, cargas, cachés y entorno virtual son artefactos de ejecución y no forman parte del código fuente.

Este directorio no define el esquema de Supabase. Los SQL antiguos fueron archivados en `scripts/sql/legacy/backend-local/`; cualquier cambio vigente debe convertirse en una migración de `supabase/migrations/`.
