# Funciones del producto

Cada carpeta contiene una experiencia completa orientada al usuario. La interfaz y los hooks exclusivos permanecen aquí; la lógica pura y reutilizable pertenece a `lib/`.

- `eterna/`: conversación, controles y ciclo de voz.
- `properties/`: alta y edición del inventario.

Cuando una pieza sea compartida por más de una función, muévela a `components/`, `hooks/` o `lib/shared/` según corresponda.
